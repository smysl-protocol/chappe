# Имена проекта

**Решение: 28.07.2026.**
**GitHub: github.com/smysl-protocol** (организация; репозиторий —
smysl-protocol/rm-smysl; имя smysl занято чужим аккаунтом с 2017).

## Smysl — протокол

**Smysl** — кодовое имя протокола смысловой связи: словарь
(rm_dict) + битовый кодек (RMCodec) + английский пивот + смысловая
петля на отправителе. Всё, что превращает живую речь в десятки байт
и разворачивает их на языке получателя.

Происхождение: русское слово «смысл», записанное латиницей — протокол
передаёт именно смысл, а не байты текста; слово короткое, произносимо
на любом языке, а его непереводимость с ходу — сама по себе метка
происхождения проекта. Совпадение с бейджем интерфейса «смысл сверен»
— приятный бонус.

## R+M — приложение

**R+M** — рабочее имя приложения (офлайн-мессенджер: LoRa-меш +
локальная LLM + EVM-кошелёк), носителя протокола Smysl. Имя
приложения может смениться к релизу; имя протокола — нет.

## Правило

Код и пути (`tools/semdict`, `ios/RM/RM/Semantic/` и пр.) НЕ
переименовываются — только документация и user-facing тексты.
Термин «семантическое сжатие» как описание МЕТОДА остаётся;
«Smysl» используется там, где речь об ИМЕНИ нашей связки.

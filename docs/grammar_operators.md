# Грамматические операторы: время на уровне фразы

> **Статус: идея зафиксирована 28.07.2026, реализация после
> стабилизации диктовки.** Код не трогать.

Проблема: словарь весь в настоящем времени, словоформы либо теряют
время в лемматизаторе (told→tell), либо плодят дубли в residual
(reschedule/rescheduled — полевое наблюдение 28.07).

Схема (двухуровневая):

1. Оператор времени ставится ОДИН РАЗ на предложение/фразу
   (диапазон 0x0100, ~6-8 бит): op_past / op_future; настоящее —
   по умолчанию, бесплатно. Маркер действует до следующего маркера
   или конца сообщения.
2. Пословный оператор — только для смены времени ВНУТРИ фразы
   («ждали два часа, а теперь поеду»).
3. Пивот-стадия: модель помечает время предложений (формат в
   промпте, например префикс [past]/[fut] на предложение),
   санитайзер конвертирует в операторы, матчер вставляет коды.
4. Рендер: увидев маркер, спрягает глаголы фразы по таблице
   (детерминированно, без модели у получателя).

Цена: ~1 байт на не-настоящую фразу вместо байта на каждый глагол;
одна точка ошибки на фразу вместо N.

Открытые вопросы: аспект (шёл/пошёл), лицо при спряжении (брать из
местоимения фразы), взаимодействие с лемматизатором residual-счётчика
(формы схлопывать в лемму, время учитывать отдельно).

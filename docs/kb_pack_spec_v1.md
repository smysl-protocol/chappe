# Спецификация пака знаний (kb_pack_spec_v1)

Дата: 02.08.2026. Пак — единица поставки знаний: один md-файл формата
kb_spec v0.2 + манифест + записи в общем реестре источников.

## Состав

```
packs/<pack_id>_v<N>.md              — канонический файл пака
packs/<pack_id>_v<N>.manifest.json   — манифест (ниже)
packs/kb_sources.json                — ОБЩИЙ реестр источников (ID, url,
                                       level, verified_at; в контекст
                                       модели не попадает)
Resources/sophie_kb/kb_<имя>_ru.md   — побайтовая копия пака в бандле
```

## Манифест

| Поле | Значение |
|---|---|
| pack_id, version | идентичность пака |
| risk_class | A (жизнь/здоровье) / B (действия) / C (справка) |
| source_document | исходник-исследование, из которого собран пак |
| used_sources | все ID источников, упомянутые секциями |
| sha256 | отпечаток канонического файла (копия в бандле обязана совпадать — тест) |
| sections, always_sections, priority_section, priority_queries | структура и приёмка ретривера |

## Правила сборки

1. Факты — только из исходника; чего нет в исходнике, нет в паке.
2. Секция самодостаточна: ответ строится из одной секции.
3. Осторожные формулировки исходника («вероятно», «акт не просмотрен»)
   сохраняются дословно по смыслу — не превращаются в утверждения.
4. URL в секциях запрещены; только ID источников
   (tools/kb/check_sources.py --strict обязан быть зелёным).
5. `always_sections` содержат правила изложения/мифы и включаются всегда.
6. `priority_queries` обязаны находить `priority_section` ретривером —
   закрепляется тестом до загрузки пака в бандл.
7. Красные фикстуры инцидентов остаются в регрессии и после загрузки.

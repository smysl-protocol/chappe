## 2. Класс 1 — ПРАВОВОЙ РИСК

### 1.1 Источники паков знаний: WHO и iFixit — РАСХОЖДЕНИЕ С БРИФОМ

Бриф говорит «WHO и iFixit под CC BY-NC-SA уже помечены флагом NC».
**Фактически в репозитории их нет вовсе**: ни текстов, ни ссылок, ни
флага NC — проверено поиском по дереву И по всей истории git
(`-S "iFixit"`, `-S "BY-NC"` — ноль коммитов). Сегодняшние паки —
авторский текст (первая помощь написана по фактам: «раствор ВОЗ» —
рецепт-факт, факты не охраняются) и исторический пак Шаппа с реестром
из 11 библиографических ссылок — **у реестра нет поля license**.

**Предложение (три пункта):**
1. В `packs/kb_sources.json` добавить обязательное поле `license` и
   `nc: true/false` каждой записи; валидатор пака (kb_pack_spec §4)
   отклоняет источник без лицензии — правило кодом, не памятью.
2. Правило для будущих паков: NC-материал (WHO-публикации, iFixit)
   в сборку App Store **не включается** — App Store-дистрибуция
   коммерческая по смыслу NC, спорить с этим в суде — не наша роль.
   Медицина и ремонт пишутся своим текстом по фактам, источники —
   ссылками в реестре.
3. Если владелец точно помнит про существующие NC-пометки — они вне
   репозитория (заметки, утраченный скретч); в репозиторий их надо
   внести заново, git-история их не содержит.

### 1.2 Планируемая лицензия проекта — не выбрана

Ничто из зависимостей не запирает выбор: всё permissive, copyleft-кода
нет. Единственная связка: **выбор лицензии — решение владельца до
опенсорса** (вместе с доменом, очередь 05.08 п.4). Замечание к GPLv3:
App Store-дистрибуция GPLv3-кода имеет известный конфликт (прецедент
VLC); если хочется copyleft — смотреть MPL-2.0 или GPL с
App-Store-исключением. Это довод, не решение.

### 1.3 Meshtastic protobufs — GPL-3.0 рядом, но не у нас

Их репозиторий protobufs — GPL-3.0. У нас производного кода **нет**:
мини-протобаф (`MiniProto` в MeshtasticLink.swift, `node_serial.py`)
написан по документации wire-формата; номера полей и UUID — интерфейсные
факты. **Правило на будущее: никогда не копировать их .proto-файлы в
репозиторий и не генерировать из них код** — иначе GPL придёт в
приложение. Оставить как есть, с этим правилом в CLAUDE.md релиза.

### 1.4 Атрибуции — выполнены, проверены в коде

- Qwen/Apache 2.0: экран «© 2024 Alibaba Cloud» — есть (AboutView).
- OSM/ODbL + OpenMapTiles/CC-BY: строка атрибуции — есть (MapScreen).
  При редизайне карты строку не терять — она правовая, не декоративная.

### 1.5 Чего НЕ делать

Замену permissive-библиотек своими реализациями не предлагаю нигде,
криптографических — особенно: своя криптография хуже любой
зависимости. CryptoKit, llama.cpp, modernc/sqlite, x/crypto остаются.

Смену формата НА ИХ стороне локальный тест поймать не может по
построению — поэтому механизм «не молча» двухступенчатый: golden-байты
ловят дрейф нашего кода, предупреждение по прошивке ловит дрейф их
стороны в момент подключения узла. Правило эксплуатации: обновление
прошивки узлов = радио-смоук до полевого использования.

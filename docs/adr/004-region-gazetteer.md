# ADR 004 — Офлайн-газеттир регионов для выбора области карты

Дата: 31.07.2026. Статус: принято (Ф2.2 брифа правок по живому прогону).

## Контекст

Выбор области для скачивания офлайн-карты по имени («Мос» → Москва /
Московская область) требует геокодера. Сторонние сетевые геокодеры
(Nominatim, Photon и подобные) отклонены сознательно: сетевая
зависимость и чужие лимиты — против принципа независимости проекта.

## Решение

Встроенный офлайн-газеттир в бандле приложения:
`Resources/geo/regions_gazetteer.json` (~3.4 МБ, 38 638 записей),
сборка — `tools/geo/build_region_gazetteer.py`.

| Слой | Источник | Записей | Лицензия |
|---|---|---|---|
| Города | GeoNames `cities15000.txt` (население ≥15 000) | 34 049 | **CC-BY 4.0** — атрибуция GeoNames уже есть в «О приложении» (газетир Софи использует тот же источник) |
| Русские имена городов | GeoNames `alternateNamesV2` (isolanguage=ru, предпочтение isPreferredName, исторические отброшены) | 13 735 | CC-BY 4.0 (тот же дамп GeoNames) |
| Области/провинции | Natural Earth `10m admin_1_states_provinces` (поля name_ru/name_en, bbox из полигонов) | 4 589 | **Public domain** («Free of known copyright restrictions», naturalearthdata.com/about/terms-of-use) — атрибуция не требуется, добавлена в ADR для честности |
| Русские имена стран | GeoNames `countryInfo.txt` + CLDR (Babel) | — | CC-BY 4.0 / Unicode License |

## Детали

- **bbox городов** — эвристика из населения (той же формулой, что
  `GazetteerStore.radiusKm`: 0.01·√pop, кламп 2–30 км). Это оценка
  «города с окрестностью», не административная граница — для выбора
  области скачивания достаточно, человек видит рамку в превью и может
  поправить руками.
- **bbox областей** — настоящий, из полигонов Natural Earth. Области,
  пересекающие антимеридиан (Чукотка), зажимаются до 180°в.д. —
  честная деградация вместо bbox на весь мир.
- **Оценка веса** пака считается ЛОКАЛЬНО из bbox и диапазона зумов
  (`TileMath.tileCount × estimatedTileBytes`) — сети не касается.
- Русское имя города — только из записей с меткой языка `ru`
  (эвристика «первое кириллическое имя» ловила осетинское «Мæскуы»
  и чувашское «Маскав» раньше «Москвы»).
- Сортировка выдачи: по населению; областям присвоен условный ключ
  1 000 000 — между мегаполисом и малым городом (у Natural Earth
  населения областей нет).

## Отвергнутые варианты

- **Nominatim/Photon/Mapbox Geocoding** — сетевые, чужие лимиты,
  зависимость. Против принципа.
- **GeoNames admin1CodesASCII для областей** — нет bbox.
- **OSM-извлечения границ** — точнее Natural Earth, но на порядки
  тяжелее по данным и парсингу; дверь открыта, формат файла не
  изменится (bbox есть bbox).

## Обратимость

Экран зависит от `RegionGazetteer.search`/`name(atLat:lon:)`;
замена источника данных = пересборка JSON тем же скриптом.

# Морфология рендера — оценка объёма (П6, 29.07.2026; кода нет)

## Задача

Коды рендерятся начальными формами: «Я не нужно много вода 2
бутылка», «Машина застряла, сходила с дороги». Согласование — падеж,
число, род, лицо, вид — детерминированными таблицами по
синтаксической рамке, без модели и без лишних байт на проводе.

## Что нужно нести в кодах, а что выводится

**Ничего нового на проводе не нужно.** Почти вся информация уже есть
или выводится из конструкции:
- ЧИСЛО: из num-юнита рядом («2 бутылка» → «2 бутылки»: правило
  числительных 1/2-4/5+ — чистая таблица, нести нечего);
- ПАДЕЖ: из предлога-кода перед словом (у/в/на/до/от/с → род./предл./
  вин.), из роли при глаголе (прямое дополнение → вин.);
- ЛИЦО/РОД глагола: лицо — из местоимения-кода (я/ты/мы уже в
  юнитах); род прошедшего — единственная НЕВЫВОДИМАЯ вещь: «я
  сказал/сказала». Варианты: (а) 1 бит пола в профиле контакта —
  ноль байт на проводе, задаётся один раз; (б) нейтральные формы;
- ВИД глагола: приблизительно из рамки (императив/прошедшее уже в
  грамматических операторах и границах).

Вывод: дополнительно кодировать нужно 0 бит на слово; опционально
1 бит пола на профиль.

## Откуда парадигмы

- **OpenCorpora** (CC-BY-SA): ~400k лемм с полными парадигмами —
  избыточно; нам нужен срез на ~1200 ru-слов словаря.
- **pymorphy2-словари** (то же ядро, готовый формат) — удобно для
  генерации среза оффлайн-скриптом.
- Альтернатива «руками»: у нас всего ~900 склоняемых слов; таблицы
  окончаний русского — ~30 парадигм существительных, ~2 спряжения +
  неправильные. Скрипт по OpenCorpora генерирует срез автоматически,
  вручную проверяются исключения.

## Объём

- Срез парадигм на словарь: ~1200 слов × ~12 форм ≈ 14k строк ≈
  **200-300 КБ JSON** в бандле (не на проводе). Генерируется
  build-скриптом из OpenCorpora, замораживается со словарём.
- Движок согласования: ~300-500 строк чистых функций (правила
  предлог→падеж, числительное→форма, подлежащее→лицо) + тесты.
- Оценка трудоёмкости: 1-2 сессии; полностью детерминирован,
  паритет py↔Swift тестами как у кодека.

## Ожидаемый эффект

На пиджин-примерах прогона: «Я не нужно много вода 2 бутылка» →
«Мне не нужно много воды, 2 бутылки»; «Бензин на 2 часа» (после Б5)
уже верно. Пиджин-индекс не меняется (он про латиницу) — меняется
читаемость; мерить придётся человеком или моделью-судьёй по шкале.

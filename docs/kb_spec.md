# Базы знаний Софи — формат и выборка (spec v0.2)

> v0.2 (02.08.2026), аддитивно к v0.1: после строки `ключи:` секция МОЖЕТ
> нести строку `метаданные: риск=<A|B|C>; уровень=[...]; источники=ID,ID`.
> Ридер её не парсит — она уезжает в тело секции и видна модели (уровень
> достоверности прямо в контексте). URL в секциях ЗАПРЕЩЕНЫ: ссылки
> живут в реестре packs/kb_sources.json, в секциях — только ID
> (проверка: tools/kb/check_sources.py --strict). Секция `ключи: всегда`
> обязана включаться в каждый ответ по теме пака. Паки собираются по
> docs/kb_pack_spec_v1.md из courced-исходников; канонический файл —
> packs/<имя>_vN.md, копия в бандле — Resources/sophie_kb/kb_*.md.

**Дата:** 26 июля 2026
**Связано:** docs/sophie_presence.md (§2 предустановленные чаты)

## Зачем

Предустановленные чаты («О приложении», «Связь», «Первая помощь», «SOS»)
отвечают из курированных локальных баз, а не из весов модели. Модель
пересказывает базу; чего нет в базе — честное «не знаю». Дообучения нет.

## Формат файла базы

- Markdown, UTF-8, в бандле приложения (Resources/sophie_kb/*.md).
- Шапка: `# База: <имя> (vX.Y, дата)` + строка `назначение:`.
- Секции: `## Заголовок`, первой строкой секции — `ключи: слово, слово, ...`
  (нижний регистр, без падежей — основы слов).
- Секция с `ключи: всегда` включается в каждый ответ этого чата (ядро).
- Секция `## Оглавление` — список тем базы; включается, когда выборка
  ничего не нашла (Кая говорит, о чём умеет).

## Алгоритм выборки (детерминированный, без ML)

1. Запрос пользователя → нижний регистр → слова.
2. Совпадение ключа и слова: ключ длиной ≥4 является префиксом слова
   или слово является префиксом ключа (грубое снятие русской морфологии:
   «кровотечение» ловится ключом «кровотеч», «жгут» — «жгут»).
3. Ранжирование секций по числу совпавших ключей (при равенстве — порядок
   в файле).
4. В промпт: секция-ядро + топ секций до бюджета ~1200 оценочных токенов
   (оценка: символы/3). Ноль совпадений → ядро + «Оглавление».
5. История чата сохраняет своё окно; бюджет знаний вычитается из общего.

## Промпт предустановленного чата

Базовый системный промпт Каи + блок:
«Ниже — выдержки из проверенной базы этого чата. Отвечай ТОЛЬКО по ним
своими словами, кратко. Если ответа в выдержках нет — скажи прямо, что
в базе этого нет, и предложи темы из базы. Не добавляй фактов от себя.»
Для «Первой помощи» дополнительно: «В конце ответа про травму/состояние
одна короткая строка: это базовые действия, не замена медицинской помощи;
при серьёзных признаках — SOS.»

## Правила содержимого

- Никаких дозировок лекарств (исключение — питьевой регидратационный
  раствор ВОЗ: это еда/вода, не лекарство).
- Никаких выдуманных возможностей приложения: пак «О приложении»
  правится под реальность каждым релизом (поле версии в шапке).
- Никаких телефонных номеров экстренных служб (страны разные, офлайн):
  формулировка «если есть обычная связь — местная экстренная служба».

## Обновление

Базы версионируются с приложением. Изменение фичей → правка app-пака в
том же PR. Кая никогда не «помнит» старую версию — файл один, в бандле.

## Правила после заморозки

1. **Пересборок нет.** `build_dict.py` содержит замок: сборка,
   меняющая смысл или длину бита ЛЮБОГО существующего кода, отказывает
   (проверено ломающей симуляцией). Разрешено только чистое добавление
   в хвост.
2. **Свободный слой append-only**: новые смыслы — новые коды с новыми
   битами, старые байты навсегда значат то же.
3. Валютная таблица (155 ISO-кодов) и субсет ISO 4217 — часть v1,
   расширение только в хвост, индекс 255 — литерал.
4. Несовпадение отпечатка таблицы у получателя → текстовая заглушка,
   блоб хранится до обновления (docs/reports/version_skew_test.md).
5. Изменение чего-либо из пунктов 1–4 = новая мажорная версия
   протокола, отдельное решение владельца.

## Что вошло (относительно v1.1)

1. **esc_extension** (долг Крафт=1.0): дерево было полным — после
   первой отгрузки словарь стал бы неизменяемым навсегда. Теперь
   зарезервирован лист + 12 бит индекса = **4096 будущих кодов**;
   узел, не знающий индекса, рендерит честный фоллбэк
   «⟨расширение N⟩», не мусор. Цена на корпусе: **0 байт** (220→220).
2. **Дешёвый литерал**: второй канонический Хаффман по символам
   (litchars_v12.json, 86 символов + escape 21 бит скаляра) вместо
   сырого UTF-8 в esc_literal/esc_name: русский литерал «привет мир»
   22→11 Б, имя «Марина» 15→11 Б. Бьёт по всему мимо словаря,
   включая имена.
3. **Гейт выбирает меньшее**: семантический блоб ≥ zlib-текста —
   уходит текст.

Правила заморозки — как v1/v1.1; litchars-таблица замораживается со
словарём. Корпуса: chat 36/36, sos 8/8.
